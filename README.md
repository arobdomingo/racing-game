# Physics-Driven Racing Game

A Unity vehicle-physics prototype exploring F1-inspired handling, drivetrain behavior, and player controls.

## Tech stack
Unity 6 (6000.1.0f1), C#, Unity physics.

## Architecture
Rigidbody and WheelColliders model vehicle motion. C# components manage torque, gearing, steering, braking, and camera behavior. Unity scenes provide environments for testing vehicle handling.

## Run locally
Open the project in Unity Hub with Unity `6000.1.0f1`, load a scene under `Assets/Scenes/`, and press Play.
